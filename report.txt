Title: SOC Log Analysis Project

Objective:
Analyze authentication logs to detect suspicious login attempts.

Tools Used:
- Git Bash
- grep
- awk
- sort
- uniq

Analysis:
Detected multiple failed login attempts from suspicious IP addresses.

Findings:
- IP 192.168.1.10 attempted login 4 times
- IP 10.0.0.3 attempted login 3 times

Conclusion:
Repeated failed login attempts indicate a possible brute-force attack.

Recommendation:
- Monitor suspicious IP addresses
- Enable account lockout policy
- Block malicious IPs if activity continues
