# SOC Log Analysis Project

## Objective
Analyze authentication logs to detect suspicious login attempts and possible brute-force attacks.

## Tools Used
- Git Bash
- grep
- awk
- sort
- uniq

## Analysis
The project analyzed authentication logs and identified repeated failed login attempts from suspicious IP addresses.

## Findings
- 192.168.1.10 attempted login 4 times
- 10.0.0.3 attempted login 3 times

## Conclusion
Repeated failed login attempts indicate a possible brute-force attack.

## Skills Demonstrated
- Log analysis
- Linux commands
- Basic SOC investigation
